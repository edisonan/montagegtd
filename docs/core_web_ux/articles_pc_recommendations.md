# Articles PC 端特殊建议

## 1. 强化侧栏导航的桌面价值

- PC 端建议保留固定侧栏，并增加：
  - 分类搜索
  - feed pin/favorite
  - 未读数排序
  - 最近访问 feed

## 2. 增加三栏模式

- 当前适合两栏，PC 端可进一步尝试三栏：
  - 左：分类/feed
  - 中：文章列表
  - 右：文章预览或摘要
- 对高频阅读者，能显著降低页面跳转。

## 3. 阅读工具条可桌面化

- 建议补充：
  - 字号切换
  - 行宽切换
  - 阅读主题
  - 双页/单页模式
  - 打开原文快捷键
- 这些能力移动端价值一般，但在 PC 深度阅读里很实用。

## 4. 标注与摘录值得做右侧抽屉

- `view` 页已有 marker 心智，PC 端很适合加：
  - 右侧摘录面板
  - 高亮列表
  - 同步到笔记
  - AI 总结/问答入口

## 5. 批量处理要前置

- 聚合阅读页适合增加桌面专属的批量操作栏：
  - 批量标已读
  - 批量稍后读
  - 批量归档
  - 批量推送 Kindle

## 6. 详情页可支持分屏阅读

- PC 端推荐支持“左正文右笔记”或“左正文右原文网页”的分屏模式。
- 对技术文章、长文分析尤其有价值。
