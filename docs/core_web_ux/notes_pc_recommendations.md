# Notes PC 端特殊建议

## 1. 编辑与列表建议双栏化

- PC 端可以做：
  - 左侧标签/来源筛选
  - 中间笔记列表
  - 右侧编辑器或预览
- 对频繁整理笔记的用户效率更高。

## 2. Markdown 编辑器可加桌面增强

- 推荐增加：
  - 分屏预览
  - 大纲导航
  - 拖拽上传图片/音频
  - 粘贴自动保存图片
  - 快捷键面板

## 3. AI 面板适合侧边抽屉

- 现有 AI 弹窗可以在 PC 端升级为右侧常驻抽屉。
- 适合承载：
  - 总结
  - 改写
  - 提炼标签
  - 生成任务
  - 生成复盘

## 4. 来源联动建议增强

- 如果笔记来自文章、任务、网页分享，PC 端适合在右侧显示来源卡片。
- 用户可一边看原文，一边整理笔记。

## 5. 语音录入建议增加转写工作流

- PC 上可以加入：
  - 波形显示
  - 分段转写结果
  - 一键转 Markdown 大纲
  - 播放时高亮对应文本

## 6. 内容管理可补齐批处理

- 笔记列表可增加桌面专属批量操作：
  - 批量设为公开/私有
  - 批量归档
  - 批量加标签
  - 批量交给 AI 处理
