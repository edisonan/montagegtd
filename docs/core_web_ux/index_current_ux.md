# Index 现有 UX 梳理

基于 `resources/views/index/index.blade.php` 及其依赖弹窗组件整理。

## 1. 页面定位

- 首页是“专注 + 待办”的双栏工作台。
- 用户核心路径是：
  - 左栏开始或记录一次番茄钟
  - 右栏快速新增和处理任务
  - 通过弹窗补充手账、任务时间、复盘评分

## 2. 信息架构

- 顶层为两列网格：
  - 左列：番茄钟与今日专注成果
  - 右列：待办输入、模式切换、任务列表
- 顶部额外保留 `doingTaskCard`，用于展示当前进行中的任务卡。
- 右侧任务面板支持收起到屏幕右侧的悬浮 dock。

## 3. 左栏专注区

### 3.1 顶部操作

- `纯净模式`：强调专注时降低界面干扰。
- `专注历史`：跳转专注记录列表。
- `记录手账`：直接打开“新增手账记录”弹窗。

### 3.2 状态机

- `focusStartSection`：默认入口，展示“开始新的番茄钟”按钮。
- `focusTimerSection`：专注进行中，核心为圆环倒计时和中央时间显示。
- `recordPomo`：专注完成后进入记录态，要求用户补充本次专注内容。

### 3.3 专注进行中交互

- 用圆环进度表达剩余时间。
- 右上角有 `discard()` 入口，可中止或放弃当前专注结果。
- 状态文案和时间数字分层显示，便于快速扫视。

### 3.4 专注完成交互

- 先给出成功反馈卡片，再要求用户补充成果内容。
- 展示开始时间和结束时间，帮助用户确认本次记录准确性。
- 输入框 placeholder 明示“可点击任务名快速添加”，说明专注与任务存在联动。

### 3.5 今日成果区

- 顶部显示今日完成专注数量。
- 列表区具有加载态，内容通过 JS 动态装载。

## 4. 右栏待办区

### 4.1 顶部操作

- `缩小`：把整个任务面板收纳到右侧悬浮按钮。
- `列表`：跳转完整任务列表。
- `四象限`：跳转任务优先级矩阵。

### 4.2 快速新增

- 页面内联单行输入框，按回车即可保存。
- 该设计优先速度，不打断用户的专注路径。

### 4.3 列表头

- 展示当前模式名。
- 提供 `切换` 按钮，说明任务区支持工作/生活模式切换。
- 右侧实时显示任务数量。

### 4.4 列表状态

- 有加载态 `tasksLoading`
- 有空状态 `tasksEmpty`
- 有真实列表 `tasks`

### 4.5 行内交互模式

- 任务项 hover 时整体轻微抬起并高亮边框。
- 任务操作区默认隐藏，hover 后显示。
- 行内视觉元素包括：
  - 自定义复选框
  - 状态点
  - 优先级 badge
  - 子任务标识
  - 操作按钮

## 5. 首页挂载弹层

### 5.1 任务编辑弹窗

- 大尺寸居中弹窗，适合复杂编辑。
- 字段覆盖：
  - 名称
  - 父任务
  - 优先级
  - 状态
  - 提醒时间
  - 截止时间
  - 是否置顶
  - 工作/生活模式
- 单选项被做成大点击面积卡片，不只是原生 radio。

### 5.2 新建手账弹窗

- 支持从首页快速补录完成事项。
- 核心增强点：
  - 常用“多少分钟前”快捷按钮
  - 开始/结束时间微调
  - 预设时长自动计算结束时间
  - 时间预览反馈
- 整体设计明显偏“快速复盘录入”而不是长表单。

### 5.3 任务时间设置弹窗

- 专门处理预计开始、预计结束、提醒时间。
- 将“任务内容编辑”和“时间排期编辑”拆开，降低表单复杂度。

### 5.4 评分与备注弹窗

- 使用星级评分 + 文本备注。
- 明显用于任务/专注后的复盘，而非普通 CRUD。

## 6. 现状 UX 特征总结

- 首页不是导航页，而是高频操作台。
- 交互目标是“尽量少跳页”。
- 通过弹窗把重操作留在当前上下文完成。
- 强调专注、任务、手账、复盘之间的连续流程。
