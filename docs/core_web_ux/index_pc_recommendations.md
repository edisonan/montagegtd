# Index PC 端特殊建议

## 1. 保留并强化双栏工作台

- PC 端最有价值的是同时看见专注和任务，不建议退化成单栏流。
- 可进一步支持列宽拖拽，让重任务用户放大右栏，重专注用户放大左栏。

## 2. 任务面板建议做成真正的可停靠侧栏

- 现有 `缩小 + dock` 已具备桌面端心智，可以继续扩展为：
  - 记住上次展开/收起状态
  - 支持固定宽度和拖拽宽度
  - 支持第二屏独立显示

## 3. 纯净模式可做桌面增强

- PC 端可加入：
  - 全屏专注
  - 隐藏导航栏
  - 仅保留计时器和当前任务
  - 多显示器下单独弹出专注小窗

## 4. 快捷键体系值得补齐

- 推荐增加：
  - `N` 新建任务
  - `Space` 开始/暂停专注
  - `J` 打开手账记录
  - `R` 打开复盘评分
  - `Esc` 关闭当前弹窗
- 该页本身就是高频操作台，桌面端快捷键收益很高。

## 5. 桌面端可增加跨模块联动面板

- 在右栏任务项 hover 时直接显示：
  - 开始专注
  - 设置排期
  - 快速补笔记
  - 记录复盘
- 这样可以让首页成为完整工作闭环入口。

## 6. 数据感知可更强

- PC 空间允许在首页增加迷你统计：
  - 今日任务完成率
  - 今日专注总时长
  - 本周连续专注天数
  - 已排期任务数
- 建议放在双栏顶部或右栏列表头部，不要打断主操作区。

## 7. 弹窗可升级为“分栏编辑”

- 对复杂任务编辑弹窗，PC 可采用左侧基础信息、右侧时间与模式的双栏表单。
- 对手账创建弹窗，PC 可让时间预览、常用时长、快捷录入信息常驻右侧摘要区。
