# Focus PC 端特殊建议

## 1. 适合补充更强的时间分析视图

- PC 端可以增加：
  - 日历热力图
  - 周/月趋势图
  - 时间段分布图
  - 专注主题排行

## 2. 列表页可以升级为“表格 + 详情侧栏”

- 左侧保留记录表格，右侧展示选中记录详情。
- 详情中可放：
  - 关联任务
  - 关联手账
  - 评分与备注
  - 相邻专注记录

## 3. 批量整理值得加入

- PC 更适合支持批量：
  - 删除
  - 合并描述
  - 批量打标签
  - 批量关联任务

## 4. 快速检索建议前置

- 增加桌面端搜索栏和过滤器：
  - 按日期范围
  - 按关键词
  - 按时长
  - 按是否已复盘

## 5. 统计页联动建议增强

- 当前已有“数据统计”入口，PC 端应与历史页形成明显双向联动。
- 例如点击统计图后回跳到对应记录区间。
