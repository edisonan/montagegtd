# Focus 现有 UX 梳理

基于 `resources/views/focus/index.blade.php` 整理。

## 1. 页面定位

- 该页是专注历史页，不负责开始番茄钟。
- 目标是回顾、统计、编辑、删除已完成的专注记录。

## 2. 页面结构

- 顶部：标题、副标题、返回首页、数据统计入口。
- 中部：三张摘要卡片。
- 下部：专注记录主列表。

## 3. 摘要卡片

- 展示总专注数、今日完成数、当前页总时长。
- 这些指标先给用户总体反馈，再进入逐条检查。

## 4. 列表区设计

### 4.1 空状态

- 空状态有图标、解释文案和返回首页入口。
- 文案强调“开始专注后这里会展示历史”，引导关系清晰。

### 4.2 桌面端

- 使用表格展示。
- 列包括：
  - 日期
  - 时间段
  - 专注描述
  - 操作

### 4.3 移动端

- 同一份数据切为卡片列表。
- 将时间放在卡片顶部，描述放在中间，操作放在底部。

### 4.4 列表细节

- 日期做了“连续记录日期折叠”，同一天后续行显示占位线。
- 记录数、当前页时长、分页信息都会实时更新。

## 5. 行内动作

- 支持编辑描述。
- 支持删除记录。
- hover 时桌面端操作更轻，移动端显式按钮更强。

## 6. 过滤与分页

- 支持 `todayOnly` 状态变量，说明代码层考虑过“仅看今日”之类模式。
- 分页区采用“上一页 / 页码 / 下一页”轻型结构。

## 7. 现状 UX 特征总结

- focus 模块当前更偏“历史台账”。
- 统计和列表并重，但分析维度仍较轻。
- 相比首页专注区，这里强调回顾和修正，而非执行。
