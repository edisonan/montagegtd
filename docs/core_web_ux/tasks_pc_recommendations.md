# Tasks PC 端特殊建议

## 1. 列表页建议升级为“可配置工作台”

- PC 端可支持列显示开关、排序、自定义密度。
- 适合增加：
  - 截止时间列
  - 提醒时间列
  - 所属模式列
  - 关联笔记数

## 2. 四象限页非常适合桌面增强

- 继续强化拖拽是正确方向。
- 可追加：
  - 同象限内排序拖拽
  - 多选拖拽
  - 框选
  - 拖到“删除/归档”回收区

## 3. 任务详情建议侧栏化

- PC 不一定每次都开大弹窗。
- 可尝试“左列表 / 右详情侧栏”模式，提高浏览和编辑连贯性。

## 4. 桌面端应补齐键盘操作

- 推荐：
  - `Enter` 快速新建
  - `E` 编辑
  - `C` 完成
  - `F` 聚焦搜索
  - 数字 `1-4` 快速切优先级

## 5. 更强的跨模块联动值得做

- 在任务行或任务详情中直接嵌入：
  - 关联笔记预览
  - 最近专注记录
  - 最近手账复盘
- PC 屏幕足够，应该减少来回跳页。

## 6. 排期能力建议前置

- 任务系统已有时间字段和首页时间设置弹窗。
- PC 端适合继续扩展为：
  - mini calendar
  - 拖拽到时间轴
  - 截止时间临近高亮
  - 与专注计划联动
