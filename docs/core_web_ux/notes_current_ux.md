# Notes 现有 UX 梳理

基于 `resources/views/notes/index.blade.php`、`update.blade.php`、`welcome.blade.php` 整理。

## 1. 页面角色拆分

- `welcome`：能力介绍页
- `index`：笔记流与创建入口
- `update`：笔记编辑页

## 2. welcome 页体验

- 通过大卡片方式介绍：
  - 浏览器插件快速摘录
  - 实时想法记录
  - 语音录入
  - 多场景使用方式
- 产品调性更偏“灵感捕获”而不是正式文档编辑。

## 3. index 笔记主页

### 3.1 顶层能力

- 挂载 AI 提问弹窗组件，说明笔记可以和 AI 联动。
- 集成 EasyMDE 和 `marked`，说明页面既支持 Markdown 编辑也支持渲染。

### 3.2 编辑器体验

- 工具栏、编辑区、预览区都做了视觉定制。
- CodeMirror 获得独立焦点态。
- 该页明显不是“纯输入框发动态”，而是轻量知识记录器。

### 3.3 录音体验

- 提供开始录音、停止录音、录音计时、录音中指示器。
- 语音录入被视为一等输入方式，而不是附属功能。

### 3.4 标签体验

- 标签以 badge 形式平铺。
- 支持 active 状态切换。
- 更偏“快速筛选心智”，而不是复杂标签管理。

### 3.5 笔记卡片结构

- 头部：用户、状态、时间、操作区
- 内容区：Markdown 渲染内容
- 媒体区：音频等附件
- AI 操作区：与内容衍生处理相关

### 3.6 状态表达

- 至少区分公开/私有两种状态。
- 用颜色和 badge 同时表达可见性。

### 3.7 内容阅读

- 长内容默认折叠，超过阈值后用渐隐遮罩提示可展开。
- 展开按钮明确提示继续阅读。
- Markdown 内容样式完整，支持代码、表格、引用、图片。

### 3.8 行内操作

- 至少有编辑、删除、点赞、AI 操作等按钮。
- 操作按钮按语义着色，hover 反馈明确。

## 4. update 编辑页

### 4.1 页面结构

- 使用单独编辑页，而非只靠弹窗。
- 顶部将页面标题、状态 badge、说明文案融合到一个卡片头中。

### 4.2 编辑体验

- EasyMDE 被进一步美化。
- 快捷标签区以网格呈现，方便一键插入。
- 录音区单独成为一段内容，而不是藏在更多选项里。

### 4.3 产品定位

- 这页更像“富笔记编辑器”，不是任务备注输入框。
- 兼顾文字、标签、语音三种记录方式。

## 5. 现状 UX 特征总结

- notes 模块强调“快速捕获 + 富内容沉淀 + AI 二次处理”。
- 首页偏流式浏览与轻编辑，编辑页偏深度整理。
- 与 articles 的关系天然适合做摘录和延伸思考。
