# Articles 现有 UX 梳理

基于 `resources/views/articles/index.blade.php`、`list.blade.php`、`view.blade.php`、`welcome.blade.php` 整理。

## 1. 页面角色拆分

- `welcome`：功能介绍与订阅阅读入口页
- `index`：聚合阅读主页面
- `list`：单个订阅源下的文章列表
- `view`：文章详情阅读页

整体上形成“介绍 -> 聚合阅读 -> 源内浏览 -> 深度阅读”的四层结构。

## 2. welcome 页体验

- 通过大卡片、渐变头图、Kindle 能力、订阅源分类、使用流程来讲清产品价值。
- 这不是纯 landing page，更像“阅读系统导览页”。
- 重点卖点有：
  - 订阅各类博客/媒体
  - 聚合阅读
  - 定时投递 Kindle

## 3. index 聚合阅读页

### 3.1 总体布局

- 左侧为粘性侧栏，右侧为文章内容区。
- 侧栏负责“按分类和 feed 找内容”，右侧负责“按状态看文章”。

### 3.2 侧栏导航

- 分类可折叠/展开。
- 分类头展示名称和文章数。
- feed 项支持 active 状态。
- 整体是“分类树 + 计数”的阅读导航模型。

### 3.3 内容区头部

- 左侧：当前状态标题和状态 badge。
- 中间：状态 tabs，说明文章至少按多种处理状态分类。
- 右侧：工具区，包括图标按钮、开关、行动按钮。

### 3.4 内容工具

- 存在图标按钮 active 状态，说明工具支持持续开关而非一次性点击。
- 有 switch 控件，说明至少包含某些布尔阅读偏好。
- 还有按钮式工具动作，适合“批量/跳转/切换视图”。

### 3.5 文章卡片

- 卡片头部展示标题和 meta。
- meta 至少包含来源、时间等基础信息。
- 卡片正文只展示预览，并带渐隐遮罩。
- 用户通过 `展开/收起` 控制阅读深度。

### 3.6 快捷操作

- 文章卡片头部存在 quick actions。
- 这些动作显然用于稍后读、标记、跳转等轻操作。

## 4. list 订阅源文章页

- 页面采用更窄的阅读宽度，弱化分类导航，强化单源阅读。
- 顶部用渐变头部突出当前 feed。
- 标题区整合：
  - feed 名
  - 订阅操作
  - feed 元信息
  - 源站链接
- 单篇卡片保留预览展开模式，适合在同一来源下连续浏览。

## 5. view 文章详情页

### 5.1 头部结构

- 渐变头部承载文章标题、来源、发布时间和操作按钮。
- 顶部 meta bar 把来源信息和操作分到左右两端。

### 5.2 正文样式

- 对标题、段落、引用、代码块、列表、图片做了完整排版。
- 正文字号和行高较舒展，明显面向长阅读。

### 5.3 细节交互

- 图片 hover 轻微放大。
- 存在 lazy image 样式。
- 存在 marker tool，说明页面支持选中文本后的标注动作。

## 6. 现状 UX 特征总结

- articles 模块是明显的“内容消费型系统”。
- 信息组织不是简单时间线，而是“来源 + 状态 + 阅读深度”三轴组合。
- 阅读体验从列表预览到详情深读层层递进。
- 桌面端价值主要来自左侧导航、宽屏排版和工具条。
