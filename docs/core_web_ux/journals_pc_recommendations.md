# Journals PC 端特殊建议

## 1. 列表页可加时间轴模式

- 除表格外，PC 端可增加按天分组的时间轴视图。
- 对回顾工作流更友好，也更适合看连续产出。

## 2. 新建与编辑可加入右侧摘要

- PC 表单空间足够，建议右侧常驻显示：
  - 本次时长
  - 是否命中番茄钟
  - 关联任务
  - 与当天其他记录的时间冲突提示

## 3. 支持批量整理

- 桌面端适合批量：
  - 删除
  - 合并重复记录
  - 重新归类到任务
  - 导出日报

## 4. 增加与专注记录对照

- PC 上可以做“双表联动”：
  - 左边专注记录
  - 右边手账记录
- 方便检查哪些专注没有沉淀为结果记录。

## 5. 输入效率可继续提升

- 支持键盘快速调整开始/结束时间。
- 支持从最近记录复制一条作为模板。
- 支持拖拽时间条快速设定区间。
