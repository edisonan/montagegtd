# Journals 现有 UX 梳理

基于 `resources/views/journals/index.blade.php`、`update.blade.php` 以及首页挂载的 `components/journal-create-modal.blade.php` 整理。

## 1. 页面角色拆分

- 首页弹窗：快速新增手账记录
- `index`：手账记录列表
- `update`：手账记录编辑页

## 2. 新建手账弹窗

### 2.1 使用场景

- 从首页专注流程中快速补录完成事项。
- 典型场景不是“写长日志”，而是快速记录完成内容和时间区间。

### 2.2 字段与交互

- 完成内容输入框
- 快速时间按钮：10 分钟前、25 分钟前、1 小时前、2 小时前
- 开始/结束时间
- `±5m` 微调按钮
- 时长下拉：自动根据开始时间推算结束时间
- 时间预览卡片

### 2.3 弹窗体验

- 顶部可直接跳转手账列表。
- 居中大弹窗，内容区滚动，底部操作栏固定。
- 打开后自动填默认时间并聚焦内容输入。

## 3. journals/index 列表页

### 3.1 页面结构

- 顶部有标题区和按钮组。
- 主体是白底表格容器，强调台账感。

### 3.2 列表项结构

- 时间列：日期 badge + 时间范围
- 内容列：图标 + 文本
- 操作列：编辑、删除等轻操作

### 3.3 空状态

- 有插画/图片、说明文案、引导链接。
- 整体比普通空表更有产品感。

### 3.4 响应式退化

- 桌面端是标准表格。
- 移动端隐藏表头，把每条记录变成纵向卡片式结构。

## 4. journals/update 编辑页

### 4.1 头部

- 使用“图标 + 标题 + 描述 + 返回列表”的组合头部。

### 4.2 表单内容

- 内容名称
- 开始时间 / 结束时间
- 每个时间都有 `±5 分钟` 微调
- 自动计算耗时
- 如果接近番茄钟时长，会给出专门提示

### 4.3 辅助信息

- 底部加入操作提示卡片，解释时间微调、时间选择、时长计算。
- 明显是为了降低表单理解成本。

## 5. 现状 UX 特征总结

- journals 模块的核心不是写作，而是“完成记录”和“时间复盘”。
- 与专注模块联系很强，带有番茄钟成果沉淀性质。
- 设计上强调快速、准确、轻负担。
