# 课程学习系统规格说明

状态：Draft
版本：0.1
日期：2026-07-17

## 1. 背景与目标

现有课程模块已经支持课程、课程项、层级结构、加入课程和基础学习进度。本规格将其扩展为一个轻量的“从学习到掌握”系统，并支持三种内容进入方式：

1. 用户在平台手动创建课程和章节。
2. 平台内 AI 生成或程序抓取课程内容。
3. 外部 OpenClaw、Skill 或脚本生成内容后，通过 API 发布到平台。

三种方式必须进入同一套课程、章节、测试和学习进度模型，避免形成三套内容系统。

## 2. 产品原则

- 平台负责内容存储、学习体验、进度和掌握度；内容生产可以在平台内，也可以在平台外。
- AI/抓取内容默认可进入草稿，不直接覆盖人工内容。
- 所有自动内容都保留来源、生成时间和幂等标识，可以追溯和去重。
- “完成章节”和“掌握知识”分开计算。
- 第一阶段保持轻量，优先复用现有 `courses`、`course_items` 和 API，不先建设复杂工作流平台。

## 3. 用户流程

```text
确定学习目标
  → 选择/创建课程
  → 按章节学习材料
  → 完成章节练习
  → 参加小测试
  → 查看解析并修正错误
  → 间隔复习
  → 完成综合实践
  → 达到掌握标准
```

### 3.1 课程创建流程

#### 平台手动创建

用户在课程管理页创建课程，手动添加 `module`、`chapter`、`video`、`reading`、`assignment` 等课程项，编辑顺序、父子关系和内容。

#### 平台生成/抓取

用户配置主题或来源，选择“立即生成”或设置周期。系统生成内容后先保存为草稿，经过检查或人工确认后发布。

#### 外部发布

OpenClaw/Skill 负责抓取、整理、生成测试，再调用 `/api/v2/courses` 和 `/api/v2/courses/{courseId}/items` 创建课程和章节。平台只负责鉴权、校验、去重和保存。

### 3.2 学习流程

用户打开课程后按结构学习。每个可学习章节记录开始时间、完成时间、最近访问时间和掌握状态；章节完成后进入测试或练习，测试结果影响掌握度和复习队列。

## 4. 内容模型

### 4.1 复用现有模型

- `courses`：课程容器、标题、描述、难度、预计时长、公开状态。
- `course_items`：模块、章节、视频、阅读、作业、测验等层级内容。
- `course_enrollments`：用户加入课程。
- `user_progress`：用户对课程项的学习进度。

### 4.2 第一阶段新增的轻量字段

建议在 `courses` 和 `course_items` 增加以下字段；字段名可以按现有数据库命名风格调整：

课程或章节通用：

- `source_type`：`manual`、`platform_ai`、`platform_fetch`、`external`。
- `source_key`：来源侧的稳定唯一键，用于幂等。
- `content_hash`：内容指纹，用于检测重复或变化。
- `generated_at`：生成或抓取时间。
- `content_status`：`draft`、`published`、`archived`。

自动生产配置可先放在课程的 JSON 配置中，避免第一阶段增加过多表：

- 来源 URL 或 RSS 地址。
- 生成主题和提示词。
- 生成频率。
- 每次最大生成数量。
- 是否自动发布。

### 4.3 后续再拆分的模型

当自动生产任务变多后，再增加：

- `course_sources`：来源和调度配置。
- `course_generations`：每次生成的状态、模型、错误和原始响应。
- `course_item_versions`：章节版本历史。
- `course_item_sources`：章节与原始材料的关联。

第一阶段不强制引入这些表。

## 5. 测试与掌握

### 5.1 小测试

每个章节可以关联一个小测试，第一版支持：

- 单选题。
- 多选题。
- 判断题。
- 简答题（先人工查看，不做自动评分）。

每道题至少包含题干、选项、正确答案、解析、难度和关联章节。AI 生成的题目必须保留 `source_type`，并允许人工编辑。

### 5.2 测试规则

- 默认每章 3～10 题。
- 章节测试通过分数默认 70%，课程可配置。
- 允许重做。
- 记录每次尝试，而不是只覆盖最后一次结果。
- 错题自动进入复习列表。

### 5.3 掌握度

第一版采用简单规则，不引入复杂学习算法：

- 完成材料：基础进度。
- 章节测试通过：增加掌握度。
- 测试连续通过两次：标记“已掌握”。
- 测试失败或复习答错：回到“需复习”。
- 长时间未复习：重新进入复习列表。

状态建议：`not_started`、`learning`、`completed`、`reviewing`、`mastered`。

## 6. 自动生成与抓取

### 6.1 统一生产流水线

```text
读取来源/主题
  → 清洗和提取正文
  → 去重和内容指纹
  → 生成章节草稿
  → 生成测试和练习
  → 基础质量检查
  → 草稿或发布
```

### 6.2 质量检查

至少检查：

- 标题和正文不能为空。
- `source_key` 或 `content_hash` 不能重复。
- 外部链接格式正确。
- 章节不应引用不存在的父级。
- 测试题必须有答案或明确标记为人工批改。
- 自动生成内容不能覆盖人工维护版本。

### 6.3 发布策略

- 手动创建：默认草稿，用户可直接发布。
- 平台 AI/抓取：默认草稿，可配置自动发布。
- 外部 Skill：允许传入 `draft` 或 `published`，但没有发布权限时只能创建草稿。
- 失败任务不产生半成品正式章节，记录错误后允许重试。

## 7. API 约定

已有接口继续作为统一入口：

```http
GET    /api/v2/courses
GET    /api/v2/courses/{id}
POST   /api/v2/courses
PUT    /api/v2/courses/{id}

GET    /api/v2/courses/{courseId}/items
GET    /api/v2/course-items/structure/{courseId}
POST   /api/v2/courses/{courseId}/items
PUT    /api/v2/course-items/{courseId}/{id}
```

后续需要补充的能力：

```http
POST   /api/v2/courses/{courseId}/generate
POST   /api/v2/courses/{courseId}/fetch
POST   /api/v2/course-items/{id}/publish
POST   /api/v2/course-items/{id}/review
GET    /api/v2/course-items/{id}/quiz
POST   /api/v2/course-items/{id}/quiz/attempts
GET    /api/v2/reviews/course-items
```

外部 Skill 只需要使用课程和课程项创建接口即可；平台生成和抓取接口属于后续增强能力。

## 8. 权限与幂等

- 课程创建者可以创建、编辑、发布自己的课程内容。
- 已加入课程的用户可以学习、测试和提交进度，但不能修改课程内容。
- 外部调用使用 PAT，并要求 `course:write` 或项目现有等价写权限。
- 创建接口支持 `source_key` 幂等：同一课程内重复提交时返回已有对象或更新草稿，不重复创建。
- 删除课程项前检查子项目、测试和学习记录；默认采用归档而不是物理删除。

## 9. 分阶段实施

### Phase 1：课程内容基础

- 平台手动创建/编辑课程和章节。
- 章节草稿/发布状态。
- 来源字段和 `source_key` 去重。
- 外部 Skill 创建课程、章节和子课时。

### Phase 2：小测试和掌握度

- 题库和章节测试。
- 测试尝试记录、解析和错题。
- 章节学习状态与掌握状态。
- 基础复习列表。

### Phase 3：平台自动生产

- 根据 URL 生成章节。
- RSS/网页抓取生成章节。
- 根据主题每日生成课程内容。
- 草稿审核、失败重试和基础调度。

### Phase 4：实践闭环

- 作业提交。
- 综合项目。
- 自动检查或人工评分。
- 根据薄弱知识点生成下一步学习建议。

## 10. MVP 验收标准

- 用户可以在平台创建课程、模块和具体章节。
- 外部 OpenClaw/Skill 可以通过 PAT 创建课程和章节。
- 同一来源重复发布不会创建重复章节。
- 章节可以保存为草稿并发布。
- 用户可以打开章节、记录进度并完成测试。
- 测试失败后能看到解析并进入复习列表。
- 章节完成和章节掌握状态可以区分。
- 不影响现有课程展示、加入课程和基础学习流程。

## 11. 暂不做

- 复杂的多 Agent 编排平台。
- 一开始就建设完整 LMS 题库后台。
- 全自动事实校验和自动评分所有题型。
- 复杂的知识图谱和自适应学习算法。
- 自动生产内容直接覆盖人工课程。
