# 更新日志

## [1.1.0] - 2026-05-28

### ✨ 新增功能

#### 🪟 悬浮窗系统
- **自动显示**：主窗口最小化时自动显示悬浮窗
- **透明设计**：半透明毛玻璃效果，美观不遮挡
- **始终置顶**：悬浮在其他应用窗口之上
- **自由拖动**：可拖动到屏幕任意位置
- **实时状态**：显示番茄钟倒计时和待办任务数
- **快捷操作**：
  - 快速启动番茄钟
  - 一键显示主窗口
  - 快速添加任务
  - 查看任务列表

#### ⏰ 智能提醒系统
- **指数退避算法**：智能检测用户活动，按以下间隔提醒：
  - 第1次：5分钟
  - 第2次：10分钟
  - 第3次：20分钟
  - 第4次：40分钟
  - 第5次：80分钟
  - 第6次：160分钟
- **活动检测**：监测鼠标、键盘和窗口焦点状态
- **个性化消息**：每个阶段有不同的提醒文案
- **点击响应**：点击通知自动打开主窗口
- **智能重置**：用户活动时自动重置提醒计数

### 🔧 技术改进

#### 用户体验
