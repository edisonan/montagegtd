# 悬浮窗和智能提醒功能说明

## 🎯 功能概述

本次更新为 Montage GTD Desktop 添加了两个重要的增强功能：

1. **最小化悬浮窗** - 应用最小化时显示浮动窗口，提供快速访问和状态显示
2. **指数退避提醒** - 智能检测用户活动状态，按指数退避算法发送提醒

## 🪟 悬浮窗功能

### 特性
- **自动显示**：主窗口最小化时自动显示悬浮窗
- **透明设计**：半透明毛玻璃效果，不遮挡其他应用
- **始终置顶**：悬浮在其他窗口之上
- **可拖动**：可以拖动到屏幕任意位置
- **实时状态**：显示番茄钟倒计时和待办任务数量

### 界面元素
```
┌─────────────────────────┐
│ 🍅 Montage GTD    − ×   │  ← 标题和控制按钮
├─────────────────────────┤
│        25:00            │  ← 番茄钟时间
│      准备开始           │  ← 状态标签
├─────────────────────────┤
│ 待办任务: 5             │  ← 任务计数
├─────────────────────────┤
│ [▶ 开始] [📱 主窗口]   │  ← 快速操作按钮
│ [+ 添加任务] [📋 查看]  │
└─────────────────────────┘
```

### 快捷操作
- **▶ 开始** - 启动番茄钟（会显示主窗口）
- **📱 主窗口** - 恢复主窗口
- **+ 添加任务** - 打开快速添加任务模态框
- **📋 查看任务** - 切换到任务视图

### 控制按钮
- **− (减号)** - 隐藏悬浮窗（可在托盘中重新显示）
- **× (乘号)** - 关闭悬浮窗

## ⏰ 指数退避提醒系统

### 工作原理

系统会监测用户的活动状态，当检测到应用长时间未使用时，按以下时间间隔发送提醒：

| 提醒次数 | 时间间隔 | 提醒内容 |
|---------|---------|---------|
| 第1次 | 5分钟 | "该回来工作了！" |
| 第2次 | 10分钟 | "时间过得真快" |
| 第3次 | 20分钟 | "保持专注" |
| 第4次 | 40分钟 | "加油！" |
| 第5次 | 80分钟 | "温馨提醒" |
| 第6次 | 160分钟 | "最后提醒" |

### 触发条件
1. **应用最小化到托盘**
2. **窗口失去焦点超过5分钟**
3. **没有任何鼠标/键盘活动**

### 重置条件
- 用户点击通知打开应用
- 用户主动切换回应用窗口
- 任何键盘或鼠标输入

### 通知示例

```
💪 该回来工作了！
您已经离开5分钟了，回来继续专注吧！

⏰ 时间过得真快
已经10分钟了，您的任务还在等待您呢！

🎯 保持专注
20分钟过去了，高效工作从专注开始！
```

## 🔧 配置选项

在 `main.js` 中可以自定义配置：

### 悬浮窗配置
```javascript
// floating-window.js
this.window = new BrowserWindow({
    width: 280,        // 宽度
    height: 180,       // 高度
    alwaysOnTop: true, // 始终置顶
    transparent: true, // 透明背景
    // ...
});
```

### 提醒间隔配置
```javascript
// reminder-manager.js
this.intervals = [5, 10, 20, 40, 80, 160]; // 分钟
```

### 启用/禁用功能
```javascript
// 在设置中控制
settings: {
    showFloatingWindow: true,  // 显示悬浮窗
    enableReminders: true,     // 启用提醒
    notifications: true        // 启用通知
}
```

## 💡 使用场景

### 场景1：多任务工作
```
1. 正在编写代码，需要参考GTD任务
2. 最小化Montage GTD → 悬浮窗自动显示
3. 查看当前番茄钟状态和待办任务数
4. 需要添加新任务 → 点击"+ 添加任务"
5. 完成添加后继续工作，无需切换窗口
```

### 场景2：专注模式
```
1. 开始一个重要的工作任务
2. 启动25分钟番茄钟
3. 最小化应用，悬浮窗显示倒计时
4. 专注于当前工作，不被其他事情打扰
5. 番茄钟结束时收到通知提醒休息
```

### 场景3：防遗忘提醒
```
1. 早上打开应用规划任务后最小化
2. 开始处理邮件，忘记了GTD任务
3. 5分钟后收到第一次提醒
4. 如果仍未响应，10分钟后再次提醒
5. 逐步增加提醒间隔，避免过度打扰
```

## 🚀 性能优化

### 资源管理
- **按需创建**：只在需要时创建悬浮窗
- **及时清理**：主窗口恢复时隐藏悬浮窗

- **智能休眠**：长时间无活动时进入低功耗模式

## 🛠️ 故障排除

### 常见问题

**Q: 悬浮窗不显示？**
A: 检查设置中的 `minimizeToTray` 是否启用

**Q: 提醒太频繁/太少？**
A: 修改 `reminder-manager.js` 中的 `intervals` 数组

**Q: 悬浮窗位置不对？**
A: 拖动到合适位置，下次会自动记忆

**Q: 如何完全禁用提醒？**
A: 在设置中关闭 `enableReminders` 选项
