# 快速开始指南

欢迎使用 Montage GTD Desktop！本指南将帮助您快速上手。

## 🚀 5分钟快速启动

### 1. 环境准备
确保您的系统已安装：
- **Node.js** (版本 16 或更高)
- **npm** (版本 7 或更高)

检查安装：
```bash
node --version
npm --version
```

### 2. 安装应用

#### macOS / Linux
```bash
# 进入桌面应用目录
cd desktop

# 安装依赖
npm install

# 启动应用
npm run dev
```

#### Windows
```bash
# 进入桌面应用目录
cd desktop

# 安装依赖
npm install

# 启动应用
npm run dev
```

或者双击运行 `start.bat` (Windows) 或 `start.sh` (macOS/Linux)

### 3. 登录账户
1. 应用启动后，输入您的邮箱和密码
2. 点击"登录"按钮
3. 成功登录后将自动同步您的任务数据

## ✅ 核心功能使用

### 创建任务
1. 点击顶部"快速添加"按钮或按 `Ctrl/Cmd + N`
2. 填写任务信息：
   - **任务名称**（必填）
   - **优先级**：高/中/低/无
   - **截止时间**（可选）
   - **详细描述**（可选）
3. 点击"添加任务"

### 管理任务
- **完成任务**：点击任务前的复选框
- **编辑任务**：点击任务右侧的编辑图标
- **删除任务**：点击任务右侧的删除图标
- **过滤任务**：使用顶部的状态和优先级过滤器

### 使用番茄钟
1. 切换到"番茄钟"视图
2. 设置工作和休息时长（默认25/5分钟）
3. 点击"开始"开始专注
4. 完成后会自动记录并提醒您休息

### 查看四象限
在仪表盘中查看任务的优先级分布：
- **红色** - 重要且紧急（立即处理）
- **橙色** - 重要不紧急（计划安排）
- **蓝色** - 紧急不重要（可以委托）
- **灰色** - 不重要不紧急（可以删除）

## 🔧 常见问题

### Q: 应用无法连接服务器？
A: 请检查：
- 网络连接是否正常
- 防火墙是否阻止了应用
- 后端服务是否正常运行

### Q: 如何修改API服务器地址？
A: 编辑 `main.js` 文件中的 `apiBaseUrl` 配置：
```javascript
apiBaseUrl: 'https://your-server.com/api/v2'
```

### Q: 数据会丢失吗？
A: 不会。应用使用本地存储保存您的token和部分数据，即使离线也能正常使用。

### Q: 如何退出应用？
A: 
- **macOS**: `Cmd + Q` 或点击菜单退出
- **Windows/Linux**: 点击右上角关闭按钮（会最小化到托盘）
- 右键托盘图标选择"退出"

## 🎯 使用技巧

### 高效工作流
1. **早晨规划**：查看仪表盘，了解今日任务
2. **优先级排序**：先处理Q1象限的重要紧急任务
3. **番茄专注**：使用番茄钟保持专注，每25分钟休息5分钟
4. **及时记录**：有新想法时立即用快速添加记录
5. **每日回顾**：查看统计数据，优化工作方法

### 最佳实践
- **任务分解**：将大任务拆分为小步骤
- **合理优先级**：不要将所有任务都设为高优先级
- **定期清理**：删除或归档已完成的任务
- **时间估算**：为任务设置合理的截止时间
- **专注单一**：一次只专注于一个番茄钟
