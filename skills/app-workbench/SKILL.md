# App Workbench

为 Montage 应用工作台提供一套稳定的创建和维护约定。目标是让龙虾、Codex 或人工操作者都能用同样的文件结构快速生成可预览、可继续编辑的小型 Web APP。

## 工作流

1. 明确应用名称、slug、用途、入口页面和是否需要数据表。slug 只能使用小写字母、数字和连字符，且必须唯一。
2. 先检查已有应用和文件，更新时按文件路径定位，不要凭名称猜测或覆盖无关文件。
3. 创建应用后，按“文件模板契约”创建文件；必须先创建 `index.html`，再创建它引用的 CSS、JS 和数据文件。
4. 保存后打开预览 URL，检查页面、交互、窄屏布局、资源路径和浏览器控制台错误；发现问题就修改对应文件并再次预览。
5. 若需要持久化业务数据，创建虚拟数据表和字段，并让前端通过工作台提供的接口读写；不要把会变化的业务数据硬编码到 HTML。
6. 最终反馈应用 ID、slug、文件清单、预览地址、数据表和验证结果。涉及代码修改时说明改了哪些文件和原因。

## 文件模板契约

默认使用以下最小结构：

```text
index.html       # 必需，唯一入口，代码类型 html，启用
styles.css       # 推荐，代码类型 css
app.js           # 推荐，代码类型 js
data.json        # 可选，代码类型 json，仅用于静态初始数据
```

硬性要求：

- 入口必须是 `index.html`；文件路径不以 `/` 开头，应用内不能重复。
- `index.html` 使用相对路径引用：`styles.css`、`app.js`，不要默认使用外部 CDN。
- CSS 放在 CSS 文件，交互放在 JS 文件；不要把大段 CSS/JS 塞进 HTML，便于工作台单文件编辑和历史版本追踪。
- 页面必须包含响应式 viewport；默认支持桌面、平板和手机宽度。
- JS 使用原生浏览器 API 或项目已确认可用的依赖；不能假设 Vue、React、Tailwind 或后端模板变量存在。
- 所有用户可见文本、按钮、空状态、加载状态和错误状态都要明确；接口失败时不能静默白屏。
- 资源引用使用相对路径并保持大小写一致。预览构建会把同一应用内的 CSS/JS 资源内联，因此路径必须与文件 `path` 完全对应。
- 新建或更新文件后都要保存；未保存的编辑器内容不算交付结果。

完整模板字段、类型映射和示例见 [references/app-contract.md](references/app-contract.md)。

当由龙虾或其他自动化代理生成 APP 时，要求它按以下信息组织请求：

```text
创建一个 Montage 应用工作台 APP：
- 名称：
- slug：
- 目标用户和主要场景：
- 页面/功能：
- 必须支持的移动端行为：
- 是否需要虚拟数据表：是/否
- 数据表、字段、字段类型和是否可空：
- 视觉方向：
- 不允许：外部 CDN、占位文字、未实现按钮、把 CSS/JS 全塞进 index.html

请输出并创建：index.html、styles.css、app.js，以及需要的 JSON 或数据表定义。
创建后逐项验证入口、资源、交互、移动端和预览。
```

## 管理规则

- 查看：先读取应用列表和文件列表，再决定操作目标。
- 创建：应用元信息 → `index.html` → 依赖文件 → 数据表/字段 → 预览验证。
- 修改：只更新明确的文件；保留现有功能，避免整页重写造成回归。
- 删除或大范围覆盖：先列出影响的应用、文件和数据表，必须得到明确确认。
- 历史版本：每次保存代码后使用历史版本确认变更；回滚前说明会覆盖当前内容。
- 预览：优先使用 `/app/{slug}/index.html`；若应用 slug 或路径异常，先检查路径是否带多余斜杠。
- 部署：若用户要求上线，部署完成后必须重新打开预览并报告线上结果；若工作区有无关改动，不要把无关文件一并发布。

## 验证清单

交付前至少确认：

- 应用存在且状态正确，slug 可访问。
- `index.html` 存在、启用、能正常加载。
- HTML 引用的每个 CSS/JS 文件都存在且路径一致。
- 桌面和窄屏布局都可用，按钮和主要交互有实际行为。
- 数据表字段与前端使用的字段名一致，空数据和接口失败有处理。
- 预览页面没有明显白屏、404 资源或 JavaScript 初始化错误。
- 交付反馈包含应用 ID、预览地址、文件和数据表清单，以及是否已部署。

## 失败处理

- 首屏慢或代码框延迟：优先检查是否把所有文件正文一次性嵌入页面；使用按文件加载的方式，不要先替换编辑器库。
- 代码框空白：检查入口文件是否返回、Ace 本地资源是否为 200、当前文件接口是否成功、编辑器容器是否有高度。
- 预览缺少样式或交互：检查 HTML 的相对引用和应用内文件路径，不要直接改成随机 CDN 地址。
- 需要后端能力但工作台没有对应接口：先说明限制，再把数据结构和前端降级方案写清楚；不要伪造成功响应。
